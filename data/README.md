# 主板数据集维护说明

`mainboards.json` 是 `search` 工具的运行时数据源，不在请求期间访问厂商网站。应用启动
组装工具时会一次性读取并通过 Pydantic 严格校验；未知字段、字段缺失、非法 URL 和重复
`id` 都会让加载失败，避免 Agent 使用部分损坏的数据。

维护约定：

1. `id` 使用稳定的小写连字符格式，已发布后不要因展示名称变化而修改。
2. 规格只录入厂商官方产品页可核验的内容，不录入价格、库存或第三方评分。
3. `source.url` 指向对应型号的厂商官方规格页，`verified_at` 记录最后人工核验日期。
4. 型号修订版存在硬件差异时应新增独立记录，不把多个修订版的规格合并。
5. 修改后运行完整质量门禁；`tests/fixtures/mainboards.json` 只服务确定性测试，不复制生产
   数据，也不随厂商规格更新。
